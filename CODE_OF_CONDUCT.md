# Code of Conduct

Agentic-QA is a technical collaboration space. Contributors should make it possible for others to inspect, reproduce, challenge, and improve the work.

## Expected

- Be specific about evidence and uncertainty.
- Critique claims, code, tests, and designs rather than people.
- Give others a reasonable path to reproduce failures.
- Respect privacy and remove secrets, private code, identifying local paths, and unrelated personal information.
- Accept correction when stronger evidence contradicts an earlier conclusion.

## Not acceptable

- Harassment, threats, discrimination, or targeted personal attacks.
- Publishing another person's private information or credentials.
- Deliberately misleading benchmark, test, or security claims.
- Repeated disruption that prevents technical collaboration.

Maintainers may edit, hide, or remove contributions that violate these expectations and may restrict participation when necessary. Use an available private GitHub contact/security channel when a conduct concern cannot safely be raised in public.
